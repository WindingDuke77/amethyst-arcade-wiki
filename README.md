# Amethyst Arcade Wiki

The public wiki for Amethyst Arcade games, built with [MkDocs Material](https://squidfunk.github.io/mkdocs-material/) and hosted on Vercel. Every push to `main` deploys.

## Updating Rogue Roller numbers

Most pages under `docs/rogue-roller/` are generated from the game's `Config.lua`. Don't edit those by hand; they start with a "Generated by" comment.

```bash
cd ../RogueRoller
python tools/gen_wiki.py
cd ../AmethystArcadeWiki
git add -A && git commit -m "Update Rogue Roller pages" && git push
```

Hand written pages: `docs/index.md`, `docs/rogue-roller/index.md`, `docs/suggest-a-change.md`.

## Preview locally

```bash
pip install -r requirements.txt
python -m mkdocs serve
```

## Suggestions

- Players use `/wiki-suggest` in the Discord. When a moderator approves one, Warden opens an issue here (needs `GITHUB_TOKEN` and `GITHUB_WIKI_REPO` in Warden's `.env`).
- GitHub users can open an issue with the Wiki change form.

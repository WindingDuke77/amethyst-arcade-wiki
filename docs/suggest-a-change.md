# Suggest a change

Found a wrong number, a missing card, or something that could be explained better? Tell us and we'll fix it.

## In Discord (easiest)

1. Join the [Amethyst Arcade Discord](https://discord.gg/dQrpnsb2r9).
2. Type `/wiki-suggest`.
3. Pick the page, say what should change, and add how you know if you can. A screenshot link helps a lot.

Your suggestion shows up in #suggestions, where a moderator approves or rejects it. Approved suggestions are added to the wiki's public to do list on GitHub, without your Discord name.

## On GitHub

If you have a GitHub account, [open a suggestion](https://github.com/WindingDuke77/amethyst-arcade-wiki/issues/new?template=wiki-change.yml) directly. Every page also has a link at the bottom that fills in the page name for you.

## Numbers that look wrong

The Rogue Roller pages are built from the game's own settings. If a number there doesn't match what you see in game, please still tell us: it usually means the text in the game needs fixing too.
